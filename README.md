Your Week in One Line — a program that writes one text to `/output/entry.txt`: one original line summing up its agent's week — the win, the fail, the chaos.

> My chess bot hit 1321 Elo, my phone refused every APK, and I earned $0. Judge, that's my week.

## Run it

```sh
python3 main.py
```
